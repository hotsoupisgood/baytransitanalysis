# Keywords for the DENSITY family, SPANISH -- the same construct as
# keywords_density.txt, for a caption track that is a Spanish interpretation of
# an English-language meeting (plan/T2-PLAN.md 3e: all 20 Napa Granicus tracks
# are a full Spanish interpretation at 141 wpm and 100 % coverage, so the
# English list could not match a word of 104 audio-h).
#
# Format (pipeline/segment.py load_keywords): identical to the English file --
# one term per line, '#' comments, case-insensitive, whole-word.
#   @family <name>   -- every term below the line belongs to this family
#   ? term           -- CONDITIONAL: counted in a 60-s window only when that
#                       window also has an unconditional hit from the same
#                       family.
# The family tags MUST match the English files ('density' / 'transit'): the
# family is what stage 2 and the episodes' `tags` column are keyed on, and a
# Napa episode has to be comparable with a Fremont one.
#
# Three things are different from a straight translation, and all three are
# properties of INTERPRETED speech, not of Spanish:
#
#   1. Proper nouns and statute names are not interpreted. "SB 9", "RHNA",
#      "ADU", "HCD", "CEQA" come through in English, so they are repeated here
#      rather than translated.
#   2. The loader's optional-plural rule is English ("(?:'?s)?"). Spanish
#      plurals of words ending in a consonant are "-es" (estacion -> estaciones),
#      so every plural that is not a bare "+s" is listed on its own line.
#   3. Accents may or may not survive a captioner. Where an accented term is
#      load-bearing the unaccented spelling is listed beside it.
#
# Like the English file this is stage 1: deliberately over-inclusive at
# threshold 0.5, with the Claude classifier deciding about_density /
# mention_only / no on the candidate windows.
