# plan/role_cues.txt -- phrase cues for scripts/role_label.py (T0 test 6,
# PROPOSAL-transit.md 3(g)). Edit freely; the script re-reads it every run.
#
# Format: `[section]` headers, one cue per line, `#` comments. A cue is a
# case-insensitive regular expression matched on whole words (a run of spaces
# matches any whitespace). Plain phrases are fine; the few that need it use
# regex syntax.
#
# Sections and what they mean to the labeller:
#   floor    said by whoever runs the floor (mayor / president / clerk) -> dais
#   timer    floor phrases that only occur DURING public comment ("that's your
#            time", "you have three minutes", "you've been unmuted") -> dais for the
#            speaker, and structural: if no opener has been seen, a timer cue
#            means the clip started inside public comment, so a region is
#            opened retroactively from the clip start (or from the last closer)
#   vote     motions, seconds, roll calls                              -> dais
#   staff    staff-report and presenter phrasing                       -> dais
#   intro    job titles, counted only in the first 15 s of a cluster's
#            speech AND in self-introduction form ("I'm ...", "my name is
#            ...", "<Name>, Housing Specialist"); "thank you, general
#            manager" is someone being addressed                       -> dais
#   address  how a dais member or staff addresses the chair            -> dais (weak)
#   public   how a public-comment speaker introduces or positions      -> public
#            themselves
#   opener   phrases that OPEN a public-comment stretch (structural cue:
#            clusters inside the stretch that speak once for <= 3.5 min are
#            public). The speaker who actually opened a region gets floor credit.
#   closer   phrases that CLOSE that stretch. Same credit rule.
#
# Weights per section are in role_label.py (WEIGHTS); the cue text is here so
# the vocabulary can be extended from new bodies without touching code.
# Cues were collected on 2026-09-21 from the b13 clips that are NOT in
# output/t0/roles/truth_10.json (BART 9FM5406YagE_e1, San Jose EqZPNTTUr8A_e3,
# Sunnyvale mpbBPvyGNMo_e2, San Rafael iyh8o9tJgVI_e1), then trimmed after the
# first scoring run (see T0-RESULTS test 6: titles moved to [intro], generic
# forms of address dropped, bare "public comment" dropped as an opener).
