# Handoff review — 2026-09-17

A full read of the repo before handing it to an OpenClaw supervisor: every file,
the 20 existing transcripts, the run logs, and the plan documents. Everything
below was reproduced before it was written down; the evidence column says how.

Severity: **A** = would have corrupted the corpus or the study design.
**B** = wrong numbers. **C** = wasted time or money. **D** = documentation.

---

## A. Would have broken the corpus build

| # | Finding | Evidence | Status |
|---|---|---|---|

Every catalog row became one column, and `build_frame.py` discarded all of them as "no date" — silently, exit code 0. | Ran yt-dlp 2026.8.19 with both quotings: `ID1\t2026...` vs a real tab. Replaying the old script produced a catalog with zero usable rows and still exited 0. | Fixed: `$'...'` ANSI-C quoting, `awk` instead of `sed` (BSD `sed` on macOS does not expand `\t` either), per-speaker row counts, non-zero exit when a channel returns nothing, bot-check detection, stderr kept in `plan/logs/`. | # | Finding | Evidence | Status |
|---|---|---|---|

| B2 | The filler list dropped **"right"** but kept **"left"**, so every left/right comparison was asymmetric by construction. | `tokens("the radical left and the far right")` → `['radical', 'left', 'far']`. | Fixed: "right" removed from `FILLERS`, with a comment; pinned by `make test` §9. |

## E. What the QA gate found in the existing outputs

`python3 analysis/qa_transcripts.py --src output/whisper --glob '*.medium.json' --subs output/subs`
→ **20 videos: 18 OK, 2 WARN, 0 FAIL**

- **`AAiFho_u_GI` at 21:39** — one 30-second segment containing "Hassan piker,"
  ×45. The audio has a ~14-second Fox News supercut of the name; Whisper's
  decoder kept looping through 21:51-22:09 and **overwrote the speech that
  follows**, which YouTube's captions do contain. This is the exact failure mode
  Phase 0 exists to catch, and it is already in the data used for the meanness
  scores.
- **`E8UfHoFc2Eo`** — the last ~35 seconds (crowd chatter) is missing; the VAD
  filter dropped it.
- WER against YouTube's ASR ranges 2.1-11.6% (median ~6%). That is
  ASR-vs-ASR agreement, not accuracy — see D5.
- Two content problems the gate cannot see, but the word lists can:
  **sponsor reads** (`com` is Ben Shapiro's single most distinctive token, in
  100% of his videos) and **name-spelling drift** (`Platner`/`Plattner`,
  `Erika`/`Erica`). `docs/MODELS.md` §6 has the mitigations.

## F. What was added

| Thing | Why |
|---|---|
| `analysis/qa_transcripts.py` | A transcript that passes silently becomes data. Screens every batch before loading: contract, coverage, speaking rate, decoder loops (gzip ratio), stock phrases, diarization sanity, WER and per-minute divergence vs captions. |
| `analysis/legacy_to_contract.py` | Lets the 20 exploratory transcripts exercise the loader and the analysis without touching the originals. |
| `scripts/smoke_test.sh`, `scripts/check_credentials.py` | The "test of systems" for a new machine, for $0. |
| `pipeline/notify.py` | One `notify(level, message)`; WhatsApp through OpenClaw, Discord as a fallback, an outbox so a message is never lost silently. |

| `ops/openclaw/*`, `ops/launchd/*` | The supervisor's operating instructions, runbooks, config examples, exec-approval allowlist, and the dashboard LaunchAgent. |
| `plan/channels.tsv` | The channel URLs are a research decision; they now live in a file Puck edits, not in a script. |
| `docs/` | This review, `TESTING.md`, `MODELS.md`, `OPENCLAW_SETUP.md`. |

   worth ten minutes before it is 300 hours deep (`PLAN.md` §9 item 9).
7. `backup.sh` uses `rclone sync` for `output/audio`. Sync mirrors deletions: if
   a local file disappears, the next run deletes the backup copy too. For files
   whose whole point is that they are expensive to re-acquire, `rclone copy`, or
   `sync --backup-dir`, is the safer verb.
